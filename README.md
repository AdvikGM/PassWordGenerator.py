# 🔐 Password Generator

A simple Python project that generates strong random passwords using letters, numbers, and symbols.

---

## 🚀 Features

- Generates random secure passwords
- User chooses password length
- Uses letters, numbers, and symbols
- Simple terminal-based program

---

## 🧠 How it works

The program:
1. Takes password length from the user
2. Combines characters (letters + numbers + symbols)
3. Randomly selects characters using a loop
4. Builds a password step by step

---

## ▶️ How to run

Make sure Python is installed, then run:

```bash
python main.py
```

---

## 📌 Example

```text
Enter Password Length: 8
Your Password is: a9@Kp2!x
```
